# Beamer template for **GALACTIC**

Usage:

~~~latex
\usetheme{GALACTIC}
\usepackage{DejaVuSans}
~~~

or use this option:

~~~latex
\usetheme[pagenumber]{GALACTIC}
\usepackage{DejaVuSans}
~~~

The output of `example.tex` gives the `example.pdf` file.

The **GALACTIC** icon has been constructed using icons present in the
[free star wars icons set](http://sensibleworld.com/news/free-star-wars-icons)
designed by [Sensible World](http://www.iconarchive.com/artist/sensibleworld.html).
